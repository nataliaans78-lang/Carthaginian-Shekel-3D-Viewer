## ✨ Overview

Interactive 3D visualization inspired by a Carthaginian electrum coin depicting Tanit and a standing horse.

- detailed 3D rendering  
- museum / gallery lighting presets  
- smooth rotate and zoom interaction  
- responsive interface  
- English, Polish, and French content

- 3D coin rendering (GLB)  
- Museum / Gallery lighting  
- Rotate / zoom interaction  
- Responsive mobile layout  
- EN / PL / FR interface

## 🧠 Tech Stack

- Next.js
